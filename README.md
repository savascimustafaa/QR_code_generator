📱 QR Code Generator

URL, metin ve daha fazlası için saniyeler içinde özel logolu ve yüksek kaliteli QR kodlar oluşturun.

📖 Proje Hakkında

QR Code Generator, web siteleri, düz metinler veya paylaşmak istediğiniz herhangi bir veri için hızlıca QR kod üretmenizi sağlayan Python tabanlı bir uygulamadır. Standart QR kodların ötesine geçerek, oluşturduğunuz QR kodun merkezine kendi logonuzu veya markanızın simgesini yerleştirebilir, taranabilirliği bozmadan kişiselleştirilmiş çıktılar elde edebilirsiniz.

✨ Özellikler

🖼️ Özel Logo Ekleme: Kendi logonuzu (PNG, JPG vb.) QR kodun ortasına kolayca entegre edin.

🛡️ Yüksek Hata Düzeltme: Logo yerleştirildiğinde bile QR kodun tüm cihazlar tarafından sorunsuz taranmasını sağlar.

⚡ Hızlı ve Pratik: Metin veya bağlantı girdikten sonra saniyeler içinde yüksek çözünürlüklü çıktı alın.

🔒 Tamamen Çevrimdışı: Tüm üretim süreci yerel bilgisayarınızda gerçekleşir; verileriniz ve logolarınız dış sunuculara gönderilmez.

🪶 Hafif Yapı: Karmaşık kurulumlar gerektirmez, doğrudan kullanıma hazırdır.

🛠️ Kurulum

Projeyi bilgisayarınızda çalıştırmak için işletim sisteminize uygun adımları izleyebilirsiniz.

🪟 Windows

Projeyi klonlayın ve klasöre girin:

git clone https://github.com/savascimustafaa/QR_code_generator.git
cd QR_code_generator


Sanal ortam oluşturun ve etkinleştirin:

python -m venv venv
venv\Scripts\activate


Gerekli kütüphaneleri yükleyin:

pip install -r requirements.txt


🐧 Linux / macOS

Projeyi klonlayın ve klasöre girin:

git clone https://github.com/savascimustafaa/QR_code_generator.git
cd QR_code_generator


Sanal ortam oluşturun ve etkinleştirin:

python3 -m venv venv
source venv/bin/activate


Gerekli kütüphaneleri yükleyin:

pip install -r requirements.txt


💻 Kullanım

Kurulum tamamlandıktan sonra uygulamayı aşağıdaki komutla başlatabilirsiniz:

python main.py


(Ana dosyanızın adı farklıysa main.py kısmını kendi dosya adınızla değiştirebilirsiniz.)

QR koda dönüştürmek istediğiniz metni veya URL'yi girin.

İsteğe bağlı olarak merkeze yerleştirmek istediğiniz logo dosyasını seçin.

QR kodunuzu oluşturun ve bilgisayarınıza kaydedin.
